# Nawaf Portfolio

Premium minimal portfolio built with React, TypeScript, Vite, Tailwind CSS v4, React Router, Framer Motion, and Lucide icons.

## Run Locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run lint
npm run build
```

## Structure

- `src/data` contains editable profile, project, experience, service, education, testimonial, and FAQ content.
- `src/components/sections` contains the main portfolio sections.
- `src/components/showcase` contains the interactive work showcase, device frames, and media controls.
- `src/pages/ProjectCaseStudyPage.tsx` renders the detailed dynamic project pages.
- `public/images/profile.jpeg` is the supplied profile image used in the hero and OG metadata.
- `public/media` contains generated screenshots and WebM walkthroughs for Madan App, Nooha, Queens Salon, and Maedin Decor.
